# Source Consistency Audit

Reviewed and maintained across brand kit iterations.

## Current System (v1.1)

- **Master Mark:** The three-line equalizer/waveform mark is established as the canonical master symbol and high-visibility favicon.
  - Proportions: 15 : 22 : 12 vertical pill geometry with shared vertical center.
  - Palette: MusicPro Blue (`#0091FF`), Green (`#2ED573`), Orange (`#F59E0B`).
- **Alternate System:** The earlier 7-bar waveform M is preserved under `logo/alternate-7bar/` for future reference or editorial variants.
- **Favicon Suite:** Complete set of vector (`favicon.svg`), multi-res ICO (`favicon.ico`), iOS touch icon (`apple-touch-icon.svg`), and crisp raster exports (16, 32, 48, 180, 192, 512).
- **Typography:** Inter, Newsreader, and JetBrains Mono retained as the core trio.
- **Design Tokens:** Modular light/dark CSS tokens retained in `tokens/`.
- **Directory Structure:** Standardized under `Brand-Kit/`.

## Legacy Cleaned Up

- Removed old Guitar Producer and Music Pro Hacks logos, circular emblem badges, and old red/indigo palettes.
- Replaced all legacy domain references (`guitarproducer.com`, `musicprohacks.com`) with `MusicPro.app`.
- Verified monochrome black and white marks use true monochrome fills (`#000000` / `#FFFFFF`).
