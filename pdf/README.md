# MusicPro PDF Guidance

Use the same MusicPro typography and color tokens as the web and application systems.

Primary typeface: Inter.
Display/editorial typeface: Newsreader.
Technical typeface: JetBrains Mono.

Use the full-color SVG mark when appropriate. Use black or white monochrome marks for print or contrast requirements.

PDFs should favor high readability, strong hierarchy, generous margins, restrained color, and clear section structure. Do not reuse the old indigo/cream application palette as the new MusicPro standard.

For automated PDF generation, embed or package the fonts locally instead of relying on a browser-only web-font import.
