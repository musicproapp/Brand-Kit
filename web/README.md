# MusicPro Web Starter Guidance

Use `../styles.css` as the base stylesheet.

Use the SVG mark from `../logo/` rather than raster logo files.

New pages should support both light and dark themes through `data-theme="light"` or `data-theme="dark"` on the root HTML element.

Keep MusicPro.app as the primary destination reference. New pages should use MusicPro naming consistently and should not reintroduce Music Pro Hacks branding.
