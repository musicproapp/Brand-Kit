# MusicPro App Guidance

MusicPro applications should inherit the master brand system while allowing product-specific UI needs.

Use the canonical SVG mark from `../logo/`.

For dense music-production interfaces, prioritize clear hierarchy, keyboard/mouse usability, readable controls, and efficient use of space. The brand should be visible without turning the application into a marketing page.

Use the dark theme when it improves long-session music-production workflows. Keep the interface neutral and use the MusicPro spectrum primarily for meaningful emphasis.
